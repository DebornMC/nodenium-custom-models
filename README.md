# Nodenium Custom Resources
Repository containing custom models and textures used on the Nodenium server. 

# Adding Models via PR (for Nodenium Members)
If you wish to add your own models, duplicate the template folder and rename it to your in-game name (must match exactly, with no uppercase letters, e.g. "ExampleName_123" must be entered as `examplename_123`). Add your models in this namespace, making sure your filenames use proper `snake_case`. Adding your name to the model is not necessary, any models you add will already be searchable by the namespace (your username).
